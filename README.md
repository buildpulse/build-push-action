# build-push-action (deprecated)

> [!WARNING]
> **This fork is deprecated.** It targeted the retired BuildPulse v1 remote-builder pool and does not work on BuildPulse v2 runners. Use the standard [`docker/build-push-action`](https://github.com/docker/build-push-action) (with [`buildpulse/setup-docker-builder`](https://github.com/buildpulse/setup-docker-builder) for layer caching) instead.

This repository is kept only so that existing workflow references keep resolving. It receives no updates.
